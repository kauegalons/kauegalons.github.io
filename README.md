# kauegalons.github.io

Meu portfólio pessoal: Java, IA e as histórias por trás de cada projeto.
Feito com [React](https://react.dev/) e [Vite](https://vitejs.dev/), publicado no [GitHub Pages](https://pages.github.com/).

🔗 **[kauegalons.github.io](https://kauegalons.github.io)**

![Página inicial](docs/preview.png)

## 🛠 instalação e ambiente de desenvolvimento

1. Instale as dependências

   ```sh
   npm install
   ```

2. Suba o servidor de desenvolvimento

   ```sh
   npm run dev
   ```

   O site abre em `http://localhost:5173`.

## 🚀 build e execução em produção

1. Gere o build estático de produção

   ```sh
   npm run build
   ```

2. Visualize o build localmente

   ```sh
   npm run preview
   ```

Todo push na branch `main` faz o build e publica no GitHub Pages automaticamente (`.github/workflows/deploy.yml`).
